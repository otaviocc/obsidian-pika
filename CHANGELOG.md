# Changelog

## [1.0.0] - 2026-04-14
### Added
- Initial release of Pika.publish, forked from the Micro.blog Obsidian plugin.
- Publish and update posts to Pika via the Micropub API.
- Image upload pipeline with `image_urls` frontmatter cache.
- Best-effort category synchronization for tag suggestions.
